# 🏢 Interactive Office Space Booker (MVP)

Современное Mobile-First веб-приложение для интерактивного бронирования рабочих мест и переговорных комнат в гибридных офисах. Проект разработан с акцентом на высокую скорость интерфейса, безопасность данных и работу в реальном времени по всей сети.

## 🚀 Зачем и для чего создан этот проект?
В условиях гибридного формата работы (когда часть сотрудников сидит дома, а часть в офисе) возникает хаос: переговорные комнаты часто заняты, а за удобные столы идёт борьба. 
**Данный продукт решает эти боли:**
* **Сотрудникам:** Позволяет за секунду спланировать день, выбрав удобный часовой слот и забронировав конкретную зону прямо на карте.
* **Администрации:** Предоставляет скрытый пульт управления для гибкого менеджмента офисного пространства, изменения сетки часов и контроля дисциплины через логи.

## 🛠️ Технологический стек и архитектура:
* **Frontend:** `React 19` (Декларативный UI, хуки `useState`, `useEffect`).
* **База данных / Бэкенд:** `Google Firebase Firestore` (Облачная NoSQL БД). Синхронизация между устройствами настроена через протокол WebSockets (`onSnapshot`), что исключает необходимость обновлять страницу.
* **Сборщик:** `Vite` (Обеспечивает мгновенный HMR при разработке).
* **Безопасность (Security):** Клиентское одностороннее шифрование паролей по алгоритму `SHA-256` (через Web Crypto API). Пароли сотрудников улетают в облако в виде хеш-строк, защищая их от кражи.
* **Интерфейс:** Чистый векторный `SVG-код`, интегрированный в компоненты, стили `Glassmorphism` (эффект матового стекла), адаптивная кроссбраузерная вёрстка и сохраняемая Тёмная тема.

## 🌟 Ключевые возможности продукта:

1. **Интерактивная 3D-схема этажа (Floor Plan):** Вместо скучных текстовых списков разработана визуальная векторная карта. Каждая зона динамически меняет цвет в зависимости от выбранного времени (Синий — свободно, Зелёный — занято вами, Красный — занято коллегой).
2. **Умные плитки времени (Time Chips):** Кастомная замена системным выпадающим спискам Select. Время переключается в один тап, мгновенно перестраивая карту под выбранный час.
3. **Личный кабинет сотрудника:** Вкладка со списком всех активных бронирований текущего пользователя на день с возможностью быстрой отмены в один клик.
4. **Скрытая панель Администратора:** Доступна под системным логином `Администратор`. Позволяет:
   * Принудительно сбрасывать чужие бронирования в случае накладки.
   * Переименовывать зоны офиса прямо на лету с записью изменений в базу.
   * Добавлять новые временные интервалы (например, вечерние смены).
5. **Глобальная лента активности (System Logs):** Администратору доступен живой лог последних 10 действий в коворкинге (кто зарегистрировался, кто занял стол, кто сбросил пароль), транслируемый из Firebase.

## 📦 Как запустить проект локально:

1. Склонируйте репозиторий:
```bash
git clone https://github.com
```
2. Установите зависимости проекта:
```bash
npm install
```
3. Запустите локальный сервер разработки:
```bash
npm run dev
```
